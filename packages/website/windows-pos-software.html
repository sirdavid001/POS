Frequently asked questions

Windows POS software questions answered.

Can I use QuickPOS on a Windows laptop?

Yes. QuickPOS runs on 64-bit Windows 10 or later, including compatible laptops, desktop computers, and Windows POS terminals.

Does QuickPOS for Windows work without internet?

After the Windows app has completed an online sync, supported sales can be recorded during a temporary connection interruption and synchronized when the connection returns. Some identity, payment, email, and security actions still require a connection.

Can I connect a barcode scanner to QuickPOS on Windows?

Yes. Compatible USB and Bluetooth barcode scanners that enter a barcode like a keyboard can be used with the QuickPOS Windows app.

Where do I download QuickPOS for Windows?

Create and activate the store account on quickpos.com.ng, then open Downloads in the account portal to get the official QuickPOS Windows installer.

Can Windows and Android devices use the same QuickPOS store?

Yes. Staff can sign in on supported Windows, Android, macOS, and Linux devices using the same store account and assigned roles.
