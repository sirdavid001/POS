Download questions

Choose and install the correct QuickPOS app.

Which devices can install QuickPOS?

QuickPOS provides installed app builds for 64-bit Windows 10 or later, Android 8 or later, Intel and Apple silicon macOS systems, and compatible 64-bit Linux systems.

Where can I download the official QuickPOS installer?

The store owner signs in to the protected QuickPOS account portal. Official installers, current version details, and available checksums appear in the Downloads section after activation.

Which QuickPOS package should I use on Linux?

QuickPOS offers a portable AppImage and a Debian package for compatible 64-bit Linux systems. Choose the format that matches how the computer is managed.

Can the installed QuickPOS app work during an internet interruption?

Yes. After an online sync, the installed app can keep supported store records available and queue supported work during a temporary interruption. Some identity, security, payment, and email actions still require a connection. Read the complete offline POS software guide.

Can one store install QuickPOS on more than one supported device?

Yes. One active store subscription covers supported devices used by that store, with staff signing in through their assigned store accounts and roles.
